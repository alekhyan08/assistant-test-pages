# Privacy Policy: Assistant Test App

Last updated: 2026-11-12

This is a small personal test project used only with a dedicated test Google account. It is not offered to the public.

## What the app accesses
- Gmail messages and Google Calendar events of the dedicated test account, to produce daily summaries,
  calendar alerts and email summaries for that account's owner.
- All of this data is synthetic test data. No real personal or sensitive information is used.

## How data is used
- Data is read only to answer the owner's requests and to run scheduled summaries.
- The app never sends email without an explicit human approval of each message.
- Data is not sold, shared with third parties, used for advertising, or used to train models.

## Storage and retention
- Credentials are kept in a cloud secret manager and working state in a private storage bucket.
- Test data and credentials are deleted or rotated when the project ends.
